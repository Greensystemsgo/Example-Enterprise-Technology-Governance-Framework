Active Directory Domain Join Checklist
=====================================

Request Information
-------------------
- Tracking ID:
- System Name:
- Environment:
- Requested Join Date:

Pre-Join Validation
-------------------
- [ ] Gate 2 approval documented
- [ ] Naming convention approved
- [ ] OU placement confirmed
- [ ] Service account requirement assessed
- [ ] Network connectivity to domain controllers verified
- [ ] Logging requirements identified (SIEM integration plan)

Join Execution
--------------
- [ ] Computer object pre-created
- [ ] Group policies linked
- [ ] Login baseline tested
- [ ] Time synchronization validated

Post-Join Tasks
---------------
- [ ] Security group memberships applied
- [ ] Delegations documented
- [ ] CMDB attributes updated
- [ ] SIEM logging verified
- [ ] Owner informed of support contacts and exception process
