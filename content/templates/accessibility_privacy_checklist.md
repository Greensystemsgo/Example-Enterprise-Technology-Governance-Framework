# Accessibility & Privacy Checklist

## WCAG 2.1 AA Compliance

### Perceivable
- [ ] **Text Alternatives:** All non-text content has text alternatives
- [ ] **Captions and Transcripts:** Audio and video content has captions and transcripts
- [ ] **Color Contrast:** Text has sufficient color contrast (4.5:1 for normal text, 3:1 for large text)
- [ ] **Resizable Text:** Text can be resized up to 200% without loss of functionality
- [ ] **Images of Text:** Images of text are avoided unless essential
- [ ] **Audio Control:** Audio can be paused or stopped
- [ ] **Visual Presentation:** Information is not conveyed through color alone

### Operable
- [ ] **Keyboard Accessible:** All functionality is available from a keyboard
- [ ] **No Seizure:** Content does not cause seizures or physical reactions
- [ ] **Navigable:** Users can navigate and find content
- [ ] **Focus Management:** Focus is visible and managed appropriately
- [ ] **Skip Links:** Skip links are provided for navigation
- [ ] **Page Titles:** Pages have descriptive titles
- [ ] **Link Purpose:** Link purpose is clear from link text or context

### Understandable
- [ ] **Readable:** Text content is readable and understandable
- [ ] **Predictable:** Web pages appear and operate in predictable ways
- [ ] **Input Assistance:** Users are helped to avoid and correct mistakes
- [ ] **Language:** Language of page and content is identified
- [ ] **Consistent Navigation:** Navigation is consistent across pages
- [ ] **Consistent Identification:** Components with same functionality are identified consistently
- [ ] **Error Identification:** Errors are identified and described to users

### Robust
- [ ] **Compatible:** Content is compatible with assistive technologies
- [ ] **Valid Markup:** HTML markup is valid and well-formed
- [ ] **Semantic Structure:** Content uses semantic HTML elements
- [ ] **ARIA Labels:** ARIA labels are used appropriately
- [ ] **Form Labels:** Form elements have proper labels
- [ ] **Table Headers:** Tables have proper headers and structure
- [ ] **List Structure:** Lists are properly structured
