Change Taxonomy and Catalog

Change Types

Normal Changes

  • Definition: Standard requests following full gate process with CAB approval
  • Characteristics: Standard business hours, full documentation, complete gate process
  • Approval Path: Full gate process (Gate 0-5) with CAB approval
  • Documentation: Complete documentation package with all required artifacts
  • Timeline: Standard processing time based on gate SLAs
  • Examples: New system deployments, major upgrades, new service implementations

Major Changes

  • Definition: High-impact changes requiring additional review and approval
  • Characteristics: Significant business impact, resource requirements, risk exposure
  • Approval Path: Full gate process with additional CAB review and executive approval
  • Documentation: Enhanced documentation with detailed impact assessment and risk analysis
  • Timeline: Extended processing time with additional review cycles
  • Examples: Infrastructure migrations, security system overhauls, major vendor changes

Standard Changes

  • Definition: Pre-approved, low-risk changes with streamlined approval
  • Characteristics: Low risk, routine operations, pre-approved procedures
  • Approval Path: Streamlined approval with periodic CAB review
  • Documentation: Standardized documentation with pre-approved templates
  • Timeline: Accelerated processing with reduced gate requirements
  • Examples: Routine maintenance, standard deployments, pre-approved configurations

Emergency Changes

  • Definition: Urgent changes with retroactive CAB review within two business days
  • Characteristics: Urgent business need, immediate implementation required
  • Approval Path: Expedited approval with retroactive CAB review
  • Documentation: Post-implementation documentation with complete evidence package
  • Timeline: Immediate implementation with retroactive review
  • Examples: Security patches, critical system fixes, emergency configurations

Standard Change Catalog

System Imaging and Deployment

  • Change Type: Standard Change
  • Description: Deployment of pre-approved system images to new or existing hardware
  • Risk Level: Low
  • Approval Requirements: Infrastructure team approval with CAB oversight
  • Documentation: Standard deployment checklist and validation report
  • Frequency: As needed for new deployments and refreshes
  • Review Schedule: Annual review of image standards and deployment procedures

Certificate Renewals

  • Change Type: Standard Change
  • Description: Renewal of SSL/TLS certificates and digital certificates
  • Risk Level: Low
  • Approval Requirements: Security team approval with automated validation
  • Documentation: Certificate renewal log and validation report
  • Frequency: Based on certificate expiration schedule
  • Review Schedule: Annual review of certificate management procedures

Firewall Rule Renewals

  • Change Type: Standard Change
  • Description: Renewal of existing firewall rules with no modifications
  • Risk Level: Low
  • Approval Requirements: Network team approval with security validation
  • Documentation: Firewall rule renewal log and validation report
  • Frequency: Based on rule expiration schedule
  • Review Schedule: Annual review of firewall rule management procedures

Monthly Patch Windows

  • Change Type: Standard Change
  • Description: Application of pre-approved security patches during scheduled maintenance windows
  • Risk Level: Low
  • Approval Requirements: Infrastructure team approval with security validation
  • Documentation: Patch deployment log and validation report
  • Frequency: Monthly during scheduled maintenance windows
  • Review Schedule: Annual review of patch management procedures

User Account Provisioning

  • Change Type: Standard Change
  • Description: Creation of new user accounts following standard procedures
  • Risk Level: Low
  • Approval Requirements: Service Desk approval with manager authorization
  • Documentation: Account creation log and validation report
  • Frequency: As needed for new employees and contractors
  • Review Schedule: Annual review of account provisioning procedures

Backup Operations

  • Change Type: Standard Change
  • Description: Routine backup operations and backup verification
  • Risk Level: Low
  • Approval Requirements: Infrastructure team approval with automated validation
  • Documentation: Backup operation log and validation report
  • Frequency: Daily/weekly based on backup schedule
  • Review Schedule: Annual review of backup procedures and schedules

Normal Change Criteria

  • Risk Level: Standard risk level
  • Resource Requirements: Standard resource requirements
  • Timeline: Standard processing timeline
  • Approval Path: Full gate process with CAB approval

Major Change Criteria

  • Business Impact: High business impact
  • Risk Level: High risk level
  • Resource Requirements: Significant resource requirements
  • Timeline: Extended processing timeline
  • Approval Path: Full gate process with additional CAB review and executive approval

Standard Change Criteria

  • Business Impact: Low business impact
  • Risk Level: Low risk level
  • Resource Requirements: Minimal resource requirements
  • Timeline: Accelerated processing timeline
  • Approval Path: Streamlined approval with periodic CAB review

Emergency Change Criteria

  • Risk Level: Variable risk level
  • Resource Requirements: Immediate resource availability
  • Timeline: Immediate implementation
  • Approval Path: Expedited approval with retroactive CAB review

Annual Catalog Review

Review Process

  • Frequency: Annual review of standard change catalog
  • Participants: CAB, technical teams, process owners
  • Scope: All standard changes, approval criteria, documentation requirements
  • Outcomes: Updated catalog, revised procedures, training materials

Review Criteria

  • Risk Assessment: Review risk levels and approval requirements
  • Process Efficiency: Assess process efficiency and improvement opportunities
  • Compliance Validation: Validate compliance with governance requirements
  • Training Needs: Identify training needs and update training materials

Catalog Updates

  • New Standard Changes: Add new standard changes based on operational needs
  • Modified Changes: Update existing standard changes based on lessons learned
  • Retired Changes: Remove obsolete standard changes
  • Documentation Updates: Update documentation and training materials

Integration with Governance Framework

Gate Integration

  • Gate 0: Change type classification required in business justification
  • Gate 1: Impact assessment includes change type validation
  • Gate 2: Technical review considers change type requirements
  • Gate 3: Procurement considers change type implications
  • Gate 4: Implementation follows change type procedures
  • Gate 5: Verification includes change type compliance validation

CAB Oversight

  • Standard Change Approval: CAB approves standard change catalog and procedures
  • Periodic Review: CAB conducts periodic review of standard changes
  • Risk Assessment: CAB validates risk levels and approval requirements
  • Process Improvement: CAB drives process improvement and efficiency gains
